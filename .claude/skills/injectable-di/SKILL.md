# Injectable DI

Container: `get_it`, generated by `injectable` / `injectable_generator`.

## Setup

```dart
// lib/di/configure_dependencies.dart
final getIt = GetIt.instance;

@InjectableInit()
Future<void> configureDependencies() => getIt.init();
```

```dart
// lib/main.dart
Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await configureDependencies();
  runApp(const App());
}
```

`getIt` is used only in `di/`, routing guards, `main.dart` and `app.dart`. Everywhere else
dependencies arrive through constructors or `context.blocFactory` (`lib/di/bloc_factory.dart`).

## Which annotation

| Class | Annotation |
|---|---|
| Repository implementation | `@LazySingleton(as: TheInterface)` |
| Cubit | `@injectable` (always a factory) |
| Use case | `@injectable` |
| Third-party type (`SharedPreferences`) | a getter / method in a `@module` |

Use `@Injectable(as: X)` / `@LazySingleton(as: X)` whenever the class implements an interface —
bare `@injectable` registers the concrete type only, and the interface won't resolve.

## Modules and `@preResolve`

```dart
// lib/di/register_module.dart
@module
abstract class RegisterModule {
  @preResolve
  Future<SharedPreferences> get prefs => SharedPreferences.getInstance();
}
```

`@preResolve` makes `getIt.init()` async — which is why `main` awaits `configureDependencies()`.

## `@factoryParam`

For values DI cannot know (another cubit from the tree, an id). A cubit takes exactly **one**
`@factoryParam`: `XCubitDeps`. See `flutter-cubits`.

## Code generation

`*.config.dart` (and `*.gr.dart`, `*.g.dart`, `*.tailor.dart`) are generated. After adding, removing
or editing any annotation:

```sh
dart run build_runner build        # one-off
dart run build_runner watch        # during development
```

## Error → cause

| Error | Cause |
|---|---|
| `Object/factory with type X is not registered inside GetIt` | annotation missing, or codegen not run since |
| `Target of URI hasn't been generated: '...config.dart'` | codegen never run in this checkout |
| Interface not resolvable although annotated | bare `@injectable` instead of `@Injectable(as: Interface)` |
| `Max number of factory params supported by get_it is 2` | more than one `@factoryParam` — use one `XCubitDeps` |
| `only factories can have parameters` | `@factoryParam` on a singleton — make it `@injectable` |
| `Factories with params can not be pre-resolved` | `@preResolve` combined with `@factoryParam` |
| Dependency arrives as `Future<T>` | `@preResolve` missing on the module member |
